2026-10-13、iPhone 16 Pro シミュレーター（iOS 18.5）で `testCameraQRCodeFlow` を実行して撮影しました。テスト用の招待データを使用しています。相手の確認とQR表示はテスト操作中の画面録画から静止画を取り出しました。

- [読み取り画面](scan-simulator.png)：シミュレーターではカメラを使用できないため、カメラ領域に実機確認の案内を表示します。
- [相手の確認](confirmed.png)：読み取り結果を確認してから撮影に進みます。
- [自分のQRコード](show-code.png)：相手に見せる招待コードです。
