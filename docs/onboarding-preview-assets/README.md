# オンボーディング比較用の写真

`onboarding-five-patterns.html` のプロトタイプ専用です。人物写真は組み込みの ImageGen で生成しました。チェキ枠は既存の `sotsugyo/Assets.xcassets/チェキ素材.imageset/チェキ素材.jpg` をHTMLから直接参照しています。

| ファイル | 生成時の指示 |
| --- | --- |
| `friends-seaside.png` | 海辺の午後、インスタントカメラを持つ20代の友人3人が自然に笑う、写真カード向けの人物を中央に置いた編集写真。文字・ロゴ・UIなし。 |
| `friends-music.png` | 夕暮れの屋上で一組のイヤホンを共有する20代の友人2人、青とピンクの空、写真カード向けの自然な編集写真。文字・ロゴ・UIなし。 |

実際のオンボーディングに採用する際は、写真の掲載方針と実装用アセットを別途決めます。
