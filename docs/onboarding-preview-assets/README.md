# オンボーディング比較用のチェキ

`onboarding-five-patterns.html` のすべての案はログイン済みPicTuneをiOS 18.5シミュレーターで開き、写真詳細画面から取得したデコチェキを使用します。

| ファイル | 内容 |
| --- | --- |
| `user-cheki-pink.jpg` | ピンクの手描きでデコったチェキ |
| `user-cheki-yellow.jpg` | 黄色とラベンダーの手描きでデコったチェキ |

この2枚はユーザーのアカウント内の写真です。写真詳細に表示されたチェキの部分だけを切り出し、JPEGに変換しました。比較用に作成した以前のサンプル画像は今回のHTMLでは使用しません。


02・03も上記の本人のチェキに統一しました。以前比較に使った花・コーヒーのストック写真は削除しました。HTMLでは元の縦横比を保ってチェキ全体を表示します。
