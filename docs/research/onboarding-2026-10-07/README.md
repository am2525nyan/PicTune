# PicTune オンボーディング参考調査（2026-10-07）

`index.html` をブラウザーで開くと、30アプリの画面・観察・出典を比較できます。画像はHTMLに埋め込まれているため、表示に外部通信は不要です。出典リンクを開く場合は通信が必要です。

## 確認範囲

- 公式Webアプリを実操作：2件（Polarr、Pixlr Editor）
- 公開されたアプリ画面記録を閲覧：24件
- 公式紹介・一部画面のみ：4件
- iPhone実機のアプリ操作：0件

「30件のアプリを実際に操作」という依頼に対して、本体操作まで到達したのは2件です。残り28件は公開資料の調査であり、同じ確認水準ではありません。ログイン・有料公開範囲を越えた操作はしていません。古い記録と時期不明の記録が含まれ、現行版の挙動は保証しません。静止画から動きを推測して断定せず、各詳細に未確認範囲を記載しました。

Canva、Shufflesは追加の確認メモとしてJSONに残していますが、メインの30件には含めていません。iOSアプリのコード変更はありません。

## 閲覧機能

検索、カテゴリ・確認方法の絞り込み、画像拡大、気になる例の保存、直近最大3件の比較、個別メモ、選択のコピーとJSON保存に対応します。保存先はブラウザーのlocalStorageです。選択とメモのファイル読み込み機能はありません。ローカルファイルでの保存可否はブラウザーに依存します。

## ファイル

- `observations.json`：出典URL、記録時期、操作内容、観察、限界、スクリーンショットの対応
- `assets/`：調査時にブラウザーで撮影した表示記録（出典ページのUIを含む）
- `report.template.html`：レポートのUI
- `build_report.py`：データと画像を埋め込む生成スクリプト
- `index.html`：単一ファイルで開ける生成済み資料
- `preview.jpg`：レポートのブラウザー表示確認

再生成：

```sh
python3 docs/research/onboarding-2026-10-07/build_report.py
```

各アプリの画像・商標はそれぞれの権利者に帰属します。デザイン検討のために参照し、出典へのリンクを併記しています。

## 確認結果

Codex内蔵ブラウザー、1280px幅で30カードの描画、検索、確認方法フィルター、詳細、画像拡大、気になる例の保存、比較、メモの再読み込みを確認しました。表示領域の画像欠落と横方向のはみ出しはありませんでした。選択のコピー・ファイルダウンロード、および全ブラウザーの互換性は未確認です。テスト用の選択・メモは確認後に解除しました。iOSアプリに変更がないためXcodeビルドは実施していません。
