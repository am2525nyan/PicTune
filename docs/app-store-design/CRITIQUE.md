## 再現方法

macOSのヒラギノ書体、Google Chrome、`playwright-core`が必要です。App Designerスキルがある環境では、リポジトリルートから以下を実行します。

```sh
node ~/.codex/skills/app-designer/scripts/shoot.mjs docs/app-store-design/explore.html --out docs/app-store-design/preview --scale 3
```

`explore.html`はリポジトリの既存画像を相対参照するため、単体で別の場所へ移動すると表示できません。共有用には`preview/sheet.png`を使用します。HTMLには検討用の注意書きがあります。PNG単体は入稿用として扱わないでください。
