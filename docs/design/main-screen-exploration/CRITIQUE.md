## 指摘と対応

1. Bのレコード中央ラベルが写真の前に出る：recordをz-index:0、sleeveを1にして独立させました。
2. Cの写真日付が箱に隠れる：箱の外へ13ptで移しました。
3. 小画面B/Cで撮影ボタンが曲の矢印・写真番号に重なる：全案の小型表示を右上44ptのカメラにしました。別の箇所に情報を動かす指摘に対する代替対応として承認されています。
4. A上部が広い：introを12px 0 16pxへ変更し、写真を32pt引き上げました。見出し34ptへの縮小のみ、全案40ptと7段階のサイズ体系を保つため採用せず、批評担当がR2で妥当と判断しました。
5. Aホーム領域のコントラスト：下24ptを不透明な背景とし、スクロール領域も24pt短縮しました。

R2後に画面のデザイン変更は行っていません。比較資料・説明のみ追加しています。
