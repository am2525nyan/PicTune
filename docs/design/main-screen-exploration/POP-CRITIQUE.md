## 指摘への対応

1. Aの花が日付を覆う：写真左辺の上へ移し、全桁を露出しました。
2. Cの喫茶店写真の日付先頭が隠れる：日付を右寄せしました。
3. Cの異なる2枚に共通日付が付いて見える：各写真の直下に2026.10.18／10.12を置き、2枚目には水平線も併記しました。
4. 小型Bでカメラが写真より目立つ：本体86→72pt、レンズ68→56pt、写真の露出を14pt増やしました。
5. Cの背景写真が主写真と競う：不透明度を.18→.12へ下げました。

5件とも批評担当が解消を確認しました。配色を暗色や無彩色に戻す指摘はなく、依頼の明るい可愛さを維持しています。

R1の警告はBの黄色・青・水色の3色系統。水色を青の同じ色相に揃えて解消しました。JSONは各shotsフォルダです。スキャンでは見つからなかった、花による日付の遮蔽と、複数写真への日付の対応を目視批評で修正しています。

静止画評価後、操作確認で回転写真の端を押すと回転角が変わりクリックが外れる場合を確認し、押下をtransform置換から濃さの変化へ変更しました。ヒット領域を動かさず、端のクリックも安定させています。通常時の見た目は変わらず、この押下時の修正は静止画再採点の対象外です。

最終操作確認では3案すべてで、主写真、背面の入り江、喫茶店の写真を開き、日付と曲、音楽なし、閉じる、Escapeを確認しました。Reduced Motionも成功し、ページエラーは0でした。記録は `shots/pop-interaction/verification.json` です。
